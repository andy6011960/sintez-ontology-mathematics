# RELAXATION_METRICS

## Статус

Канонический документ.

Настоящий документ определяет количественные характеристики, вычисляемые во всех версиях симулятора.

---

# Назначение

Цель настоящего документа — определить единый набор метрик для сравнения различных релаксационных геометрий при одинаковом конечном квантовом канале.

Все версии симулятора должны вычислять данные метрики одинаковым способом.

---

# M1. Эквивалентность конечного канала

Определяет совпадение конечного квантового канала сравниваемых протоколов.

Основная величина:

* максимальное trace distance между конечными состояниями тестового набора.

Назначение:

подтверждение корректности эксперимента.

---

# M2. Длина релаксационной траектории

Определяет суммарное изменение квантового состояния в процессе релаксации.

Вычисляется как сумма расстояний между последовательными состояниями.

Назначение:

сравнение геометрии релаксационных процессов.

---

# M3. Потеря когерентности

Определяет скорость исчезновения квантовой когерентности.

Вычисляется по изменению недиагональных элементов матрицы плотности.

Назначение:

сравнение механизмов релаксации.

---

# M4. Энтропия

Определяет изменение степени смешанности состояния.

Основная величина:

энтропия фон Неймана.

Назначение:

оценка информационной динамики системы.

---

# M5. Trace Distance

Определяет расстояние между состояниями различных протоколов на каждом временном шаге.

Назначение:

выявление расхождения промежуточной динамики.

---

# M6. Время достижения устойчивого режима

Определяет номер временного шага, после которого изменение состояния становится меньше заранее заданного порога.

Назначение:

сравнение скорости релаксации.

---

# M7. Формирование записи

Определяет момент возникновения устойчивого различимого состояния.

Данная метрика является рабочей гипотезой настоящего эксперимента.

Её окончательная математическая формализация может уточняться в последующих версиях.

---

# Общие требования

Все вычисленные метрики должны сохраняться:

* в машинном формате;
* в человекочитаемом формате;
* вместе с идентификатором запуска;
* без изменения после завершения расчёта.

---

# Изменение метрик

Добавление новых метрик допускается.

Изменение определения существующих метрик требует выпуска новой версии эксперимента.
