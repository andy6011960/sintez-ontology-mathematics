# EXPERIMENT_INVARIANTS

## Статус

Канонический документ.

Изменение любого инварианта означает создание новой версии эксперимента.

---

# Назначение

Настоящий документ определяет инварианты, обязательные для всех запусков эксперимента версии 1.x.

---

# Онтологический инвариант

Предметом исследования является процесс релаксации квантовой системы.

Эксперимент не исследует происхождение квантовой механики, а проверяет операционные следствия IV интерпретации.

---

# Физический инвариант

Во всех экспериментах сохраняются:

* трёхкубитная модель системы;
* открытая квантовая система;
* описание динамики средствами стандартной квантовой механики;
* единый тип измерительного контекста для сравниваемых протоколов.

---

# Экспериментальный инвариант

Во всех сериях сравниваются только два релаксационных протокола.

Изменение геометрии релаксации допускается.

Изменение предмета сравнения не допускается.

---

# Инвариант конечного состояния

Сравниваемые протоколы должны иметь:

* одинаковый конечный квантовый канал;
* одинаковый конечный измерительный контекст (POVM).

При нарушении данного условия эксперимент считается некорректным.

---

# Инвариант воспроизводимости

Каждый запуск должен быть полностью воспроизводим.

Все параметры эксперимента сохраняются вместе с результатами.

---

# Инвариант происхождения

Исторические материалы предыдущего эксперимента не изменяются.

Новый эксперимент сохраняет происхождение, но не изменяет исторические артефакты.

---

# Инвариант регистрации

Каждый запуск получает собственный идентификатор и полный комплект результатов.

Перезапись результатов предыдущих запусков запрещена.

---

# Инвариант интерпретации

Порядок анализа является обязательным:

1. Проверка математической корректности.
2. Проверка воспроизводимости.
3. Физический анализ.
4. Онтологическая интерпретация.

Нарушение данного порядка не допускается.

---

# Правило изменения инвариантов

Если хотя бы один инвариант настоящего документа изменяется, эксперимент считается новой версией и должен получить новый номер.
