# CHANNEL_DERIVATION

## Статус

Канонический математический документ.

Все версии симулятора должны удовлетворять приведённому выводу.

---

# Назначение

Настоящий документ определяет математическое условие эквивалентности конечного квантового канала для сравниваемых протоколов релаксации.

Цель состоит в том, чтобы сравнивать различные релаксационные геометрии при одинаковом конечном воздействии на квантовую систему.

---

# Протокол A

Во время каждого временного шага действует одинаковый механизм фазовой декогеренции.

Пусть коэффициент сохранения когерентности одного шага равен

g.

После N последовательных шагов итоговый коэффициент когерентности становится

g_A = g^N.

---

# Протокол B

Первая половина эволюции проходит без декогеренции.

Во второй половине используется усиленная фазовая декогеренция.

Пусть коэффициент сохранения когерентности одного усиленного шага равен

g'.

После N/2 усиленных шагов итоговый коэффициент когерентности становится

g_B = (g')^(N/2).

---

# Условие эквивалентности

Для корректного сравнения релаксационных траекторий конечный квантовый канал должен быть одинаковым.

Следовательно,

g_A = g_B.

Подставляя выражения для обоих протоколов, получаем

g^N = (g')^(N/2).

---

# Решение

Возводим обе части равенства в степень 2/N.

Получаем

g' = g².

---

# Следствие

Если во втором протоколе использовать коэффициент

g' = g²,

то оба протокола обладают одинаковым конечным квантовым каналом.

При этом их промежуточная релаксационная динамика остаётся различной.

Именно эта различная геометрия релаксации является предметом настоящего исследования.

---

# Практическое применение

Все версии симулятора обязаны вычислять параметры второго протокола на основании данного соотношения.

Ручное изменение коэффициента g' не допускается.

При необходимости исследования других условий должна быть создана новая версия эксперимента.
